# webgl-model-viewer
Simple web app for viewing models using webasm

# Requirements
rustc
cargo
wasm-pack
node
npm

# Notes
This package has been superceded by https://github.com/stamps9k/webgl-full-stack & https://github.com/stamps9k/wasm-model-viewer-core which implement a site that is more configurable and can demonstrate greater capability for scaling in the future.  

# Use
To build the rust webasm part of the project, run the command wasm-pack build in the webasm directory.
To run the application use the command npm start in the website directory
